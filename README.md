# Sistema Pescador — Downloads

## Atualização validada: 1.0.0-rc.56-acessos.1

Aplicativo Windows x64 e GuiaBridge 0.5.53 em um único instalador.

[Baixar instalador](https://github.com/j4xmine/sistema-pescador-download/releases/download/v1.0.0-rc.56-acessos.1/SistemaPescador-Atualizacao-1.0.0-rc.56-acessos.1.exe)

[Notas e integridade dos arquivos](https://github.com/j4xmine/sistema-pescador-download/releases/tag/v1.0.0-rc.56-acessos.1)

No aplicativo, clique em **Verificar atualizações**, abra o download, feche o sistema e execute o instalador sem desinstalar a versão atual. O botão abre o download; a instalação é feita pelo usuário.

Inclui alternância entre Entidade Admin e Plataforma Admin na mesma conta autorizada, foto própria de perfil, painel e boas-vindas renovados, indicação de situação financeira, filtro de pagamentos e melhorias na administração da plataforma. Preserva banco local, documentos e configurações. É uma atualização para computadores com o sistema já instalado.

O backend RC56 já foi instalado no servidor em uso. Não é necessário repetir a atualização da EC2 em cada computador. A concessão de acesso adicional à plataforma é feita pelo superusuário atual; a instalação não concede privilégios nem ativa MFA automaticamente.

O pacote é o mesmo executável validado pelo responsável, sem recompilação, com SHA-256 `3f3f98de177e7f7f60c57638e14657e08619d8a4d91294012117a12dde7676cd`.

As versões anteriores permanecem no [histórico de releases](https://github.com/j4xmine/sistema-pescador-download/releases).
