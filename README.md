# Sistema Pescador — Downloads

## Atualização validada: 1.0.0-rc.57-cadastro-gps.2

Aplicativo Windows x64 e GuiaBridge 0.5.53 em um único instalador.

[Baixar instalador](https://github.com/j4xmine/sistema-pescador-download/releases/download/v1.0.0-rc.57-cadastro-gps.2/SistemaPescador-Atualizacao-1.0.0-rc.57-cadastro-gps.2.exe)

[Notas e integridade dos arquivos](https://github.com/j4xmine/sistema-pescador-download/releases/tag/v1.0.0-rc.57-cadastro-gps.2)

No aplicativo, clique em **Verificar atualizações**, abra o download, aguarde qualquer emissão terminar, feche o sistema e execute o instalador sem desinstalar a versão atual. O botão abre o download; a instalação é feita pelo usuário.

A RC57 permite cadastrar outro pescador enquanto as guias continuam sendo geradas. Use **Cadastrar outro pescador** ou **+ → Cadastrar pescador** e depois **Voltar à emissão** para acompanhar. O rascunho fica preservado ao alternar, com proteção para a emissão e para o cadastro do pescador em processamento.

Inclui também as melhorias da RC56: alternância de acesso na mesma conta autorizada, foto de perfil, filtros de pagamentos e administração da plataforma. Preserva banco local, documentos e configurações. É uma atualização para computadores com o sistema já instalado.

Não é necessária nova atualização do backend RC56 já instalado no servidor em uso. A instalação não concede privilégios nem ativa MFA automaticamente.

O pacote é o mesmo executável validado pelo responsável, sem recompilação, com SHA-256 `ac79c05977205ea8b0b124dd2d9264a68186e600f842cd7bbb4c46abdd171065`.

As versões anteriores permanecem no [histórico de releases](https://github.com/j4xmine/sistema-pescador-download/releases).
