# Sistema Pescador — Downloads

## Atualização validada: 1.0.0-rc.52-duas-etapas.1

Aplicativo Windows x64 e GuiaBridge 0.5.53 em um único instalador.

[Baixar instalador](https://github.com/j4xmine/sistema-pescador-download/releases/download/v1.0.0-rc.52-duas-etapas.1/SistemaPescador-Atualizacao-1.0.0-rc.52-duas-etapas.1.exe)

[Notas e integridade dos arquivos](https://github.com/j4xmine/sistema-pescador-download/releases/tag/v1.0.0-rc.52-duas-etapas.1)

No aplicativo, clique em **Verificar atualizações**, abra o download, feche o sistema e execute o instalador sem desinstalar a versão atual. O botão abre o download; a instalação é feita pelo usuário.

Inclui verificação em duas etapas e códigos de recuperação, as melhorias financeiras da RC51, menu animado, abas, edição após salvar cadastro e importação de documentos. Preserva banco local versão 12, documentos e configurações. É uma atualização para computadores com o sistema já instalado.

A instalação não ativa MFA automaticamente. A configuração continua restrita às contas liberadas no servidor. Atualize todos os computadores usados por uma conta antes de ativar nela. O backend MFA rc52.3 já foi instalado no servidor em uso; este instalador não altera o servidor.

As versões anteriores permanecem no [histórico de releases](https://github.com/j4xmine/sistema-pescador-download/releases). Não reverter um servidor com contas MFA ativas a uma versão sem MFA.
