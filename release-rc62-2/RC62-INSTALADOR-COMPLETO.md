# RC62.2 — instalação completa e atualização

Um único instalador atende computadores novos e já instalados. Não exige RC30, RC31 ou qualquer versão anterior. Inclui aplicativo RC62 estável, GuiaBridge 0.5.58, ScannerBridge 2.0.2 e Microsoft Visual C++ x64 com assinatura validada. Componentes .NET autocontidos.

Feche o Sistema Pescador e aguarde operações terminarem antes de executar. Dados, documentos, agenda e configurações existentes são preservados; os binários anteriores são copiados para `C:\Sistema Pescador\Backups\Desktop-pre-...`. Cria atalhos no menu Iniciar e área de trabalho. Reinstalar permite reparar componentes ausentes. Versões futuras/desconhecidas não são rebaixadas.

Nenhuma atualização do backend é necessária. A rede corporativa continua em desenvolvimento separado. O aplicativo não é aberto automaticamente pelo instalador elevado: use o atalho após concluir.

Validar instalação limpa, reinstalação, atualização desde RC30/RC31/RC57/RC61/RC62, falha de backup, reparo de componentes, atalhos e integridade dos arquivos em Windows descartável. Testes usam dados sintéticos; scanner físico e emissão GOV não são executados pelo instalador.
